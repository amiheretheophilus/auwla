| 2026-10-21 | An unknown call is never re-run just because its component updated; a computation re-runs only when an input changed. | 2026-10-21 | A host global the program never writes is not an input: `Math`, `setInterval`, `document.title`, `console` never make a value reactive. A statement that only possibly builds a value (an unknown call given the value or a callback) runs once and joins the derivation only if that run changed the value; it no longer makes its binding opaque.
